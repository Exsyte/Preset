# Preset

- [`presetmon2/`](presetmon2/README.md) - PresentMon 2 benchmark preset (capture config, metrics and HTML report)
  that reproduces the FrameCap example results; also converts CapFrameX captures to PresentMon 2 CSVs.

Run the tests with `python -m unittest discover -s tests -t .` (Python 3.8+, standard library only).
